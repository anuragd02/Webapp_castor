# Castor Disease Classification Dashboard 🌿

A deep learning–based web application for detecting **Botrytis Grey Mold (BGM)** disease in castor crops using image classification.

The system uses a CNN-based TensorFlow model to classify uploaded crop images into:

* Healthy
* Unhealthy

When disease symptoms are detected, the platform provides:

* Automated spray advisory
* Fungicide recommendations
* Disease symptom information
* DSS-based treatment guidance

The dashboard is designed to support rapid field-level disease screening and assist farmers and researchers with early disease management decisions.

Built using:

* Python
* Streamlit
* TensorFlow
* NumPy
* PIL
